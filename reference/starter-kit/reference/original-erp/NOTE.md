# Read-only reference — the full original oil-mill ERP source

This is the complete working code of the project the starter kit was extracted from (Riwayat Oils and
Fats / "Tehzeeb" ERP: procurement, inventory with FIFO batches, production with costing, toll
processing, sales, finance, HR & payroll). It is NOT meant to run from here (no package.json,
requirements, config) — it exists so Claude can COPY PROVEN PATTERNS into the new project.
See ../../docs/REFERENCE_MAP.md for "I need X -> copy file Y".
Business-specific names (oil, ghee, toll, batch, tank, GRN...) belong to that business; adapt, don't import blindly.
PHASE_HISTORY_README.md is the original build log (what each phase added and why).
